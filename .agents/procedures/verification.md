# Проверка изменений

Процедура. Не Rule и не отдельная категория документации; процессная часть `AGENTS.md`. Объём проверки выбирай соразмерно риску; полную проверку для мелкой правки не запускай.

## Команды

- Сборка: `npm run build` (`ng build`, production-конфигурация по умолчанию).
- Тесты: `npm test` (`ng test`, Karma + Jasmine).

Других подтверждённых команд проверки нет.

## Выбор проверки

- Только документация или правила — проверка приложения не нужна.
- Локальная правка без изменения поведения (типы, имена, текст) — достаточно `npm run build`.
- Изменение поведения компонента, сервиса, guard, interceptor или модели — `npm run build` и релевантные specs через `npm test`.
- Изменение конфигурации сборки, окружений или зависимостей — `npm run build`; при риске для тестов дополнительно `npm test`.
- Не запускай весь набор тестов, если можно ограничиться затронутыми файлами. Готового фильтра Karma в проекте нет; если ограничить нельзя, зафиксируй это.

## Правила отчёта

- Не утверждай, что проверка прошла, если команда не запускалась.
- Указывай точную команду и результат.
- Если проверка недоступна или упала по инфраструктурной причине, отделяй это от результата изменения.

Состояние тестовой инфраструктуры и известные ограничения фиксируются отдельно как факты текущей реализации; процедура их не дублирует.
