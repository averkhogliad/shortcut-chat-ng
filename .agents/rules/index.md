# Правила frontend

Файлы в этом каталоге — обязательные нормы для `client-ng`. Индекс только маршрутизирует к нужному файлу и не заменяет его содержимое.

Применяй файл, если задача затрагивает его область:

- `architecture/index.md` — обязательные архитектурные границы и ограничения изменений.
- `architecture/api-contracts.md` — обязательное правило сохранения и согласования API-контрактов.
- `development/index.md` — маршрутизатор по соглашениям разработки и проверке.
- `testing/index.md` — когда читать процедуру проверки.
- `.agents/procedures/verification.md` — процедура выбора и выполнения проверок; не Rule и не отдельная категория документации.

Требования и контракты ищи в `openspec/specs/`. Серверный REST/SSE-контракт — в `../../../backend/openspec/specs/system/rest-api/spec.md`.

Читай только релевантные файлы. Перед изменениями изучи применимые Rules. Если сомневаешься, применим ли файл, прочитай его.
