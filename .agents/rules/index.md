# Правила frontend

Файлы в этом каталоге — обязательные правила для `client-ng`. Индекс только направляет к нужному файлу и не заменяет его содержимое.

Применяй файл, если задача затрагивает его область:

- `architecture/index.md` — компоненты, маршруты, DI, границы UI и сервисов.
- `architecture/api-contracts.md` — REST- и SSE-контракты, заголовки, base URL.
- `development/conventions.md` — стек, структура кода, стиль, безопасные изменения.
- `testing/verification.md` — выбор и запуск проверок.

Правила применения:

- Читай только файлы, релевантные текущей задаче. Не читай все правила заранее.
- Перед изменениями изучи применимые файлы.
- Если сомневаешься, применим ли файл, прочитай его. Не угадывай содержание.
- Требования отдельной функции ищи в задаче или спецификации, а не выводи из этих правил.

Справочные сведения о проекте — `.agents/context/frontend.md`. Это не обязательные правила; читай их только при необходимости обзора.
