# Тестирование

Процедура проверки — `.agents/procedures/verification.md`.

Читай её, если задача:

- меняет код компонентов, сервисов, guards, interceptor или моделей;
- меняет тесты или тестовую конфигурацию;
- требует выбрать команду проверки или заявить, что проверка пройдена.

Для изменений только в документации или правилах проверка приложения не требуется.

При проектировании тестов `createdAt` не требует обязательного преобразования в `Date`: Spec требует явного mapping, а тип и способ преобразования остаются открытым вопросом.
