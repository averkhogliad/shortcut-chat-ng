# Тестирование

Читай `verification.md`, если задача:

- меняет код компонентов, сервисов, guards, interceptor или моделей;
- меняет тесты или тестовую конфигурацию;
- требует выбрать команду проверки или заявить, что проверка пройдена.

Для изменений только в документации или правилах проверка приложения не требуется.
